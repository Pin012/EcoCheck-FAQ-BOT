# 🌲 生態檢核智能諮詢系統 (EcoCheck FAQ RAG System)

這是一款專為工程顧問公司與其業主打造的 AI 智能問答平台。本系統能讀取您上傳的專案規範、報告或會議紀錄等文件，並運用最先進的 LLM（大型語言模型）技術，精確地針對使用者的提問給予專業解答，大幅降低翻閱繁雜文件的時間成本。


---

## 🌟 系統亮點 (Features)

1. **專業智能問答 (RAG 技術)**：運用「檢索增強生成 (Retrieval-Augmented Generation, RAG)」技術，AI 僅會嚴格依據您上傳的文件內容進行回答，避免產生虛構的資訊（幻覺），確保給業主的資訊具備高度的專業性與可靠性。
2. **多格式文件支援**：支援業界最常用的文書檔案格式，包含 `.pdf`, `.docx`, `.xlsx`, `.txt`, `.csv`, `.md`, 與 `.markdown`。
3. **直覺的跨平台介面**：前端採用現代化響應式設計（RWD），無論使用電腦瀏覽器或手機查看，都能享有流暢的對話體驗。
4. **檔案直放管理**：知識庫文件統一放在 `documents/` 資料夾，由伺服器啟動時自動同步，維運流程更單純。

---

## 🧱 系統架構簡介 (Architecture Overview)

本系統將「使用者介面（前端）」與「資料處理中心（後端）」整合在同一個輕量級的運行環境中，方便您部署與維護。

*   **前端 (使用者介面)**: 使用 React 與 Tailwind CSS 打造。負責呈現對話問答視窗。
*   **後端 (伺服器與 AI 引擎)**: 使用 Node.js (Express) 打造。負責接收檔案、解析文字、管理儲存庫，並負責與 Google Gemini AI 模型進行通訊。
*   **資料儲存**: 本系統採用輕量級的檔案系統（直接將解析後的文字儲存於伺服器的 `db.json`，來源文件置於 `documents/`），不需另外架設複雜的資料庫系統，非常適合初期快速部署與測試。

## 🚀 快速啟動指南 (Getting Started)

欲在您的電腦或伺服器上運行本系統，請依循以下步驟：

### 1. 環境準備
請確保您的電腦已安裝 [Node.js](https://nodejs.org/) (建議安裝 v18 以上版本)。

### 2. 安裝依賴套件
開啟系統終端機 (Terminal) 或命令提示字元，進入本專案資料夾，執行以下指令下載所需套件：
```bash
npm install
```

### 3. 設定環境變數 (API 金鑰)
本系統依賴 Google 的 Gemini API 來生成回答。
1. 在專案的根目錄下，找到 `.env.example` 檔案。
2. 將其複製並重新命名為 `.env`。
3. 打開 `.env` 檔案，填入您的 Google Gemini API 金鑰：
   ```env
   GEMINI_API_KEY="請在這裡填寫您的_GEMINI_API_KEY"
   # 遇到額度/錯誤時的備援模型（可填多個，逗號分隔）
   GEMINI_FALLBACK_MODELS="gemini-2.0-flash-lite,gemini-2.0-flash,gemini-1.5-flash-8b,gemini-1.5-flash"
   ```
   > 預設主模型為 `gemini-2.5-flash`。若主模型報錯或配額不足，系統會自動改用 `GEMINI_FALLBACK_MODELS` 設定的較輕量模型。

### 4. 啟動系統
執行以下指令來啟動系統引擎：
```bash
npm run dev
```
當您看到終端機顯示 `Server running on http://localhost:3000` 時，即代表系統啟動成功！

## 📖 操作手冊 (How to Use)

系統啟動後，請開啟瀏覽器並根據以下網址進行操作：

### 第一步：建立知識庫 (documents 資料夾)
為了讓 AI 有資料可以參考，請先把文件放進專案根目錄的 `documents/` 資料夾。
1. **支援格式**：`.pdf`, `.docx`, `.xlsx`, `.txt`, `.csv`, `.md`, `.markdown`。
2. **放置檔案**：將知識文件直接複製到 `documents/`。
3. **重啟服務**：執行中的服務請重啟 `npm run dev`，系統啟動時會自動同步文件到知識庫。

### 第二步：開始諮詢 (前台問答)
文件上傳完畢後，即可讓業主或專案成員開始發問。
1. **前往網址**：輸入 `http://localhost:3000/` 進入智能問答介面。
2. **提出問題**：在下方輸入框提出有關生態檢核的問題，AI 將即時為您翻閱上傳的文件並給出精準回覆。

## 🗂️ 專案目錄說明 (Folder Structure)

為了方便日後維護，以下是專案重要檔案的說明：

*   `/server.ts`：後端伺服器的核心檔案。負責讀取 `documents/`、解析文字，以及呼叫 AI 回答問題。
*   `/src/App.tsx`：前端介面的核心檔案。包含「問答介面 (ChatView)」畫面與互動邏輯。
*   `/documents/`：(系統自動產生) 存放「伺服器本機直放」的知識庫文件，重啟後自動同步。
*   `/db.json`：(系統自動產生) 存放已解析的檔案文字與摘要紀錄。若欲清空所有資料，可直接安全地刪除此檔案，並重啟服務重新同步 `documents/`。

## 🤝 維護與注意事項

1. **隱私與機密限制**：上傳之檔案將作為提供給 AI 分析之用，若文件具有高度機密性，請務必先將機敏資料去識別化，或確保您的雲端提供商 (Google) 服務條款符合貴公司的資安規範。
2. **資料庫升級**：目前系統為「MVP（最小可行性產品）」階段，採用檔案系統 (db.json) 每當發問時將全部文件送給 AI。若日後累積成百上千份文件，建議後續委託工程團隊擴充為「向量資料庫 (Vector Database)」，以提升大規模檢索效率。

擁有這套系統，將能大幅提升您的顧問服務品質與效率，祝您開發順利！
